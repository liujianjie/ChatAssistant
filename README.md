# ChatAssistant - 个性化聊天助手

让 AI 学习你的聊天风格，帮你生成符合个性的回复建议。

## 功能特点

✅ **风格学习** - 分析你的聊天记录，学习你的幽默方式、常用语、话题偏好
✅ **智能推荐** - 基于对话上下文，生成3-5条符合你风格的回复建议
✅ **多平台支持** - 支持微信、Soul、小红书等平台的聊天记录
✅ **隐私保护** - 所有数据存储在本地，仅在生成建议时调用 AI API

## 快速开始

### 1. 运行程序

```bash
cd ChatAssistant
dotnet run --project ChatAssistant.Desktop
```

或者直接运行编译后的可执行文件：
```bash
ChatAssistant.Desktop\bin\Debug\net9.0-windows\ChatAssistant.Desktop.exe
```

### 2. 配置设置

首次打开，点击右上角 **⚙️ 设置** 按钮：

- **Claude API Key**: 从 https://console.anthropic.com/ 获取
- **你的名字**: 输入你在聊天记录中的昵称（如："我"、"张三"）

保存后即可使用。

### 3. 导入聊天记录

点击 **📂 导入聊天记录** 按钮：

1. 选择聊天记录文件（.txt 或 .csv 格式）
2. 输入对方名字
3. 选择平台（微信、Soul、小红书等）
4. 点击导入

**支持的文件格式：**

#### 微信文本格式 (.txt)
```
2024-02-20 19:30:15 小美
在干嘛呢

2024-02-20 19:31:20 我
刚下班，累死了哈哈
```

#### CSV 格式 (.csv)
```
时间,发送者,内容
2024-02-20 19:30:15,小美,在干嘛呢
2024-02-20 19:31:20,我,刚下班累死了哈哈
```

**提示**: 项目根目录有 `示例聊天记录.txt` 可供测试使用。

### 4. 分析聊天风格

导入聊天记录后，点击 **🤖 分析我的风格** 按钮。

AI 会分析：
- 幽默类型（自嘲、冷幽默、梗文化等）
- 常用词汇和短语
- 话题偏好
- 情感表达方式
- 回复风格

分析完成后会显示结果摘要。

### 5. 开始聊天

点击 **💬 打开聊天助手** 按钮，进入聊天助手界面：

1. **对话历史（可选）**: 输入之前的对话内容，每行一条
2. **对方最新消息**: 输入对方刚发的消息
3. 点击 **生成回复建议**

AI 会生成 3-5 条符合你风格的回复，每条包括：
- 回复内容
- 类型（幽默、关心、调侃等）
- 推荐理由
- 置信度

点击 **📋 复制** 按钮可快速复制回复内容。

## 技术栈

- **.NET 9.0** - 现代化 C# 开发
- **WPF** - Windows 桌面界面
- **Claude API** - AI 风格分析和回复生成
- **SQLite** - 本地数据存储
- **MVVM** - 清晰的架构模式

## 注意事项

⚠️ **隐私提醒**：
- 聊天记录仅存储在本地数据库
- AI 分析时会将数据发送到 Claude API
- 请勿导入包含敏感信息的聊天记录

⚠️ **API 费用**：
- 使用 Claude API 会产生费用
- 风格分析：约 $0.01-0.03 per 分析
- 回复生成：约 $0.005-0.01 per 次

⚠️ **最佳实践**：
- 导入至少 50 条消息以获得更准确的风格分析
- 回复建议仅供参考，请根据实际情况调整
- 保持对话的真实性和真诚感

## 常见问题

**Q: 为什么导入失败？**
A: 检查文件格式是否正确，确保时间格式为 `2024-02-20 19:30:15`。

**Q: 风格分析需要多久？**
A: 通常 10-30 秒，取决于消息数量和 API 响应速度。

**Q: 生成的回复不符合我的风格？**
A: 尝试导入更多聊天记录，或在聊天助手中提供更多对话历史。

**Q: 能导入多个人的聊天记录吗？**
A: 可以！每次导入都会创建新的会话，互不影响。
